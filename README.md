A bilingual portfolio project focused on implementing **internationalization (i18n)**. Built with React, TypeScript, TailwindCSS, and i18next.

## ✨ Features

- 🌍 **Bilingual Support** - Seamless switching between two languages
- 🔧 **i18next Integration** - Professional internationalization library
- 📱 **Responsive Design** - Works on all devices with TailwindCSS
- 🟦 **TypeScript** - Type-safe codebase
- 📦 **Lightweight** - Pure React (no Next.js overhead)

## 🛠️ Tech Stack

- **Framework:** React 18
- **Language:** TypeScript
- **Styling:** TailwindCSS
- **i18n:** i18next + react-i18next

## 🚀 Installation & Running

**Prerequisites:** [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) (or npm/yarn)

```bash
# 1. Clone the repository
git clone https://github.com/ansariahmadreza/BilingualSite.git

# 2. Navigate into project folder
cd BilingualSite

# 3. Install dependencies
pnpm install

# 4. Run development server
pnpm start
